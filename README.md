# Welcome to DeutschCards 🇩🇪👋

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

A React Native app that generates German sentences
for language learners using the [Tatoeba API](https://api.tatoeba.org/).

## ✨ Features

- Random German sentences
- Many translations
- Flashcard-style learning

```bash

npm install
npx expo start
```
